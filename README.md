# 人龙舞数字文创馆

以国家级非物质文化遗产“龙舞（湛江人龙舞）”为文化母题的单页数字展馆。项目作品名：**岭南人龙舞 · 非遗文创产品设计**。

**设计主张：不做文物的复刻，而做精神的再造。**  
**核心方法：把“人链”变成可以生长的图形语法。**

## 打开方式

- **直接双击** `启动网站.bat`，或双击 `index.html`。
- 推荐使用 Microsoft Edge / Google Chrome，建议 1440 × 900 以上分辨率。
- 展示前按 **F11** 进入全屏，页面会自适应桌面、平板与手机。
- 整个网站可离线运行，不依赖任何外部字体、CDN 或网络接口。

## 比赛展示快捷键

| 操作 | 功能 |
| --- | --- |
| `P` / 顶部“一键演示” | 进入评委演示模式，每 8 秒自动巡览一个章节 |
| `Space` | 暂停 / 继续自动演示 |
| `←` `→` | 演示模式下切换章节；周边章节内切换产品 |
| `Esc` | 退出演示 / 关闭目录 / 关闭大图 |
| 右上角 `MENU` | 打开全部十个章节的目录 |
| 点击色卡 | 复制色值 HEX |
| 拖拽前后对照 | 查看早期概念稿与定稿展板 |
| 勾选印前核查 | 五项全部确认后出现“可打样”印章 |
| 点击展板 / 产品 | 打开大图，可点击图片继续放大，`←` `→` 切换 |

## 页面结构

1. **序章** — 主视觉、项目信息、进入展览
2. **源流** — 湛江东海岛、国家级非遗 Ⅲ-4、表演程式与时间线
3. **破题** — 可交互动画：从散落的人到连接成龙
4. **双 IP** — 小湛龙 / 小玲珑人设与正、侧、背三视图
5. **系统** — 标志三步合成、图元演化、线稿推演、标准字与五色系统
6. **周边** — 11 类产品陈列、分类筛选、材质工艺参数、自动巡展
7. **工艺** — 6 种工艺、4 个关键参数、五项印前核查
8. **档案** — 六阶段流程、早期稿与定稿对比、创作草图档案
9. **展板** — 双展板完整陈列与海报组
10. **价值** — 文化—转译—产业三层价值、传播与产业意义

## 设计技术

- 纯静态 HTML / CSS / JavaScript，无构建步骤、无第三方运行时依赖。
- Canvas 实时绘制“人链—成龙”演示与首屏人形光点。
- IntersectionObserver 控制逐段揭示、计数器与章节主题切换。
- 支持 `prefers-reduced-motion`，自动关闭装饰动效。
- 响应式断点：1180 / 980 / 760 / 520 px。
